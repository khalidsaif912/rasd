# رصد

يراقب حسابات إنستغرام العامة ويلخّص نص كل منشور ظاهر.

```powershell
python server.py
```

ثم افتح http://127.0.0.1:8777/

لا يُحفظ دخول إلى إنستغرام، والحسابات الخاصة تبقى خارج القراءة. تُراجع الحسابات كل ثماني دقائق تقريبًا ما دام `server.py` يعمل. اختصار `Rasd` في مجلد بدء تشغيل ويندوز يشغّل `scripts/keep_running.bat` ويعيد تشغيل الخادم إذا توقف.
