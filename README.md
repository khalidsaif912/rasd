# رصد

يراقب حسابات إنستغرام العامة ويلخّص نص كل منشور ظاهر.

الموقع: https://khalidsaif912.github.io/rasd/

قراءة الحسابات تتم على خوادم GitHub كل ساعة تقريبًا. إضافة حساب أو إزالته من الموقع تفتح طلبًا في المستودع، ويُقبل الطلب إذا كان من صاحب الحساب.

التشغيل على هذا الجهاز ما زال ممكنًا:

```powershell
python server.py
```

ثم http://127.0.0.1:8777/

لا يُحفظ دخول إلى إنستغرام، والحسابات الخاصة تبقى خارج القراءة.
